# Projet Bataille Navale

Jeu de bataille navale en Python, avec des sorties colorées grâce au module [termcolor](https://github.com/termcolor/termcolor).

## Installation

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

## Lancement

```bash
python main.py
```
